# SCOOP RUN
새로 디자인한 성인 여자 디저트 가게 직원이 재료를 모으는 러닝 게임입니다.
핑크 모자와 앞치마, 갈색 포니테일. 기존 브랜드 캐릭터·로고·사진은 사용하지 않습니다.

## 플레이
화면/점프 버튼/스페이스/위쪽 화살표로 점프 및 2단 점프.
딸기·망고·쿠키·모찌·블루베리·그래놀라 각각 2개 이상 모아 매장 도착 시 클리어.
하트 3개, 약 60초. 일시정지·재도전·1080×1920 결과 카드 저장.

## 배포
기존 GitHub yochi-run 저장소의 파일 6개를 같은 위치에 덮어쓰고 Commit changes.
저장소 이름은 그대로 둬도 됩니다. Vercel 자동 배포 후 Ready 확인.
새 저장소는 scoop-run, Vercel Framework Other, 빌드 명령 없음, 출력 디렉터리 `.`.

## 구조
engine.js 게임 규칙 및 레벨 / game.js 캐릭터·배경·아이템·입력 / style.css 디자인 / index.html 화면.
index.html을 브라우저로 열어 로컬 플레이도 가능합니다.
통계·순위·서버 데이터 저장은 아직 포함하지 않습니다.
